LJC Assemblies

LJC .NET common solutions are contained in the LJCAssemblies5 folder of a codeline.

LJC .NET utility solutions are contained in the LJCUtilities5 folder of a codeline.

Solution folders contain the suffix "S5" to differentiate them from a potential project folder of the same name. This prevents accidentally overlaying the solution folder with the project folder or the project folder with the solution folder.

The namespace used for all assemblies in a solution is the same name as the solution.

Folder and file names start with the characters "LJC" to differentate them from other folders and files.
Folder and file names end with "5" to differentiate them from .NET Framework folders and files. This prevents accidentally overlaying .NET Framework folders or files.

The output assembly names start with the characters "LJC" to differentiate them from other assemblies.
The output assembly names end with "5" to differentiate them from .NET Framework assemblies. The prevents accidentally overlaying .NET Framework assemblies

The contained class and other type names do not have to end with "5" as they are unique within the assembly and class.
They will not conflict with LJC .NET Framework types of the same name as LJC .NET objects are not used with LJC .Net Framework objects.
